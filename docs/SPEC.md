# DESARROLLAR APP PREMIUM DE HÁBITOS + PRODUCTIVIDAD + IA

Quiero que desarrolles una aplicación web completa, lista para producción, preparada para GitHub, Supabase y Vercel.

NO quiero una aplicación genérica de hábitos.

Quiero un producto que parezca un SaaS premium.

La aplicación debe sentirse como una mezcla entre:

* Habit Tracker
* Sistema de productividad
* Dashboard personal
* Planificador inteligente
* Asistente de organización diaria

---

# OBJETIVO

Ayudar a una persona a:

* construir hábitos

* medir progreso

# IA DE PLANIFICACIÓN DIARIA

Esta es la función más importante.

Debe existir una sección:

"Planificador Inteligente"

El usuario escribe:

* tareas
* hábitos
* actividades

Ejemplo:

* Gimnasio 1 hora
* Estudiar 2 horas
* Trabajar 4 horas
* Leer 30 minutos

También informa:

* hora de despertar
* hora de dormir

La IA debe:

1. Calcular horas disponibles.

2. Distribuir automáticamente las actividades.

3. Crear un cronograma.

4. Completar espacios libres.

5. Agregar descansos.

6. Agregar ocio saludable.

7. Evitar sobrecarga.
